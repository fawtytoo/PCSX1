# PCSX1

## About

This is a Sony Playstation 1 emulator based on PCSX-Reloaded.

The emulator is monolithic and requires no plugins.

## Interface

Designed to be as simple to use as possible.

## Joysticks

There is support for joysticks but only tested with official Sony Playstation
joystick with USB adapter.

## Loading games

PCSX1 is command line driven. Configuration files are text files that specify
disc images and other options.

## Games

Games need to be ripped to bin/toc format.
